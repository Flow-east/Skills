## 使用原则

本文件提供“应该研究什么”，不提供“目标用户一定有什么痛点”。所有品类内容都是假设生成器，必须结合用户资料、产品事实、评论、访谈、售后记录、竞品信息或公开研究校正。

不要先选一个模板再把产品硬塞进去。先判断产品的决策机制：体验型、参数型、来源信任型、流程效率型、结果服务型，或它们的组合。

## 通用研究框架

### 产品层

- 用户购买的是实物、软件、内容、服务还是组合交付？
- 核心使用过程是什么？价值发生在哪一步？
- 哪些价值能当场展示，哪些只能长期验证？
- 产品不适合谁？使用前提和限制是什么？
- 用户现在用什么替代方案？切换成本是什么？

### 人群层

- 谁最频繁遇到这个问题？
- 谁最有解决意愿和支付能力？
- 使用者、付款者和决策者是否同一个人？
- 新手、熟练用户和团队负责人关注点有何不同？

### 场景层

- 痛点发生在什么时间、地点、任务和上下游关系中？
- 用户刚刚做了什么，接下来必须做什么？
- 哪个瞬间最容易让他承认“这说的是我”？

### 痛点层

- 表面问题是什么？根因是什么？
- 旧办法为什么不够好？
- 不解决会损失时间、金钱、体验、信任还是机会？
- 痛点是高频小烦恼，还是低频高损失？

### 决策层

- 用户首先怀疑效果、价格、适配、学习成本、售后还是风险？
- 他需要看到什么证据才会相信？
- 什么最小动作能让他安全地向前一步？

## 痛点优先级

给候选痛点按五项评分，每项 1-5 分：

| 维度 | 问题 |
| --- | --- |
| 频率 | 目标人群多久遇到一次？ |
| 强度 | 当下有多难受或多昂贵？ |
| 紧迫 | 为什么现在要处理？ |
| 相关 | 产品是否直接影响它？ |
| 可证 | 直播能否让观众看见改善？ |

优先使用总分高且证据充分的痛点。不要只选择情绪最强、但产品无法直接解决的问题。

## 品类研究问题

### 美妆个护与效果型产品

- 适用肤质、发质、年龄或使用环境是什么？
- 用户最担心的效果问题发生在哪个细节？
- 能否用近景、半脸、持妆、吸油、卸除或材质测试证明？
- 哪些功效、成分、检测和适用性需要资质或边界？
- 色号、肤感、过敏、使用顺序和退换是哪些人群的主要顾虑？

### 食品饮料与来源信任型产品

- 谁在什么家庭、办公、运动或送礼场景下食用？
- 口感、配料、规格、保存、食用方式和复购理由是什么？
- 产地、原料、工艺、检测或供应链有哪些可核验证据？
- 能否现场试吃、冲泡、切开、称重或对照配料表？
- 哪些营养、健康和功效表达不能越界？

### 服饰鞋包与上身体验型产品

- 主要身材、尺码和穿着场景是什么？
- 面料、版型、厚薄、弹性、垂感和做工如何展示？
- 能否用不同身材试穿、动作测试和细节特写证明？
- 用户最担心尺码、色差、起球、透不透、退换还是搭配？

### 3C 家电与参数型产品

- 用户真正完成的任务是什么，而不是只看哪些参数？
- 参数差异如何转化成速度、稳定性、续航、噪声或兼容体验？
- 能否现场跑测试、连接设备、测量、对比或拆解？
- 系统、接口、尺寸、网络、电压和环境限制是什么？
- 保修、安装、数据安全、售后和长期成本如何说明？

### 日用家居与高频场景型产品

- 一天中的哪个重复动作最麻烦？
- 使用前后能否立即看见清洁、收纳、操作或空间变化？
- 材质、耐用、容量、安全和清洁维护怎样证明？
- 用户原有工具为何不够，替换是否值得？

### 软件、SaaS 与数字工具

- 用户当前工作流由哪些步骤和工具组成？断点在哪里？
- 软件改善的是时间、协作、质量、可见性还是错误率？
- 哪条最短路径能从输入演示到可见输出？
- 哪些能力只是辅助，哪些需要人工确认？
- 账号、数据、兼容性、学习成本、价格版本、导入导出和售后是什么边界？
- 普通通用工具能做什么，这个产品为何仍值得使用？不要虚假贬低替代品。

### 课程、知识产品与陪跑

- 学员当前水平、目标和时间投入是多少？
- 课程交付的是知识、练习、反馈、社群还是结果路径？
- 能否先交付一个方法、练习或诊断，让用户判断教学方式？
- 结果依赖哪些学员行为，哪些不能保证？
- 课程周期、更新、答疑、退费和适用人群是什么？

### 高客单服务、搭建与咨询

- 服务开始前如何诊断和评估？
- 交付分几步，由谁配合，周期和验收标准是什么？
- 哪些案例与当前客户条件真正可比？
- 能否展示过程证据、方案前后、真实交付物或上游能力？
- 地区、设备、场地、排期、修改次数、售后和不可控因素是什么？
- 最合理的下一步通常是咨询、评估或预约，不一定是直接付款。

## 研究方法

按以下优先级获取信息：

1. 用户提供的产品说明、合同、页面、演示、客服记录和历史话术。
2. 产品真实界面、实物、交付流程和内部负责人确认。
3. 目标用户评论、售前问题、售后问题、访谈和真实搜索词。
4. 官方产品页、平台规则、资质与监管来源。
5. 竞品页面和公开讨论，仅用于生成假设，不能证明本产品能力。

输出时注明哪些结论来自证据，哪些仍是假设。研究材料不足时，给出候选痛点并让用户校正，不要假装已经洞察用户。
