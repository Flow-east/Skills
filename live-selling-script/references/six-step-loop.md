## 循环总览

六步循环描述的是观众状态变化，不是六段固定文案：

`拉新进场 -> 痛点信任 -> 方法交付 -> 互动确认 -> 痛点延伸 -> 行动指令`

一个循环通常控制在 5-10 分钟。长直播通过重复循环构成，每轮更换痛点、人群、证据或异议，不为数小时直播编造一份不会被照念的超长稿。

## 六个阶段

### 1. 拉新进场

**观众状态**：刚进入，不知道这场直播和自己有什么关系。

**目标**：让一个具体人群在一个具体场景中认出自己。

**有效内容**：正在发生的困难、反常识判断、眼前可见的变化、明确的适用人群。

**避免**：空泛欢迎、立刻报全套功能、命令式“别走”“先别划走”、无法兑现的悬念。

### 2. 痛点信任

**观众状态**：觉得问题相关，但还不相信主播真正理解。

**目标**：讲出问题发生的过程、旧办法和真实代价。

**有效内容**：具体动作、时间、环境、失败经历、用户原话、主播亲历。

**避免**：只堆“贵、慢、麻烦、低效”等形容词；为了放大痛点而虚构后果。

### 3. 方法交付

**观众状态**：愿意继续听，但在判断直播是否只是广告。

**目标**：先提供一个不购买也有用的方法、判断或检查步骤。

**有效内容**：三步判断、选择标准、避坑点、现场诊断、最小实践。

**避免**：把产品功能伪装成方法；铺垫很久却没有信息增量。

### 4. 互动确认

**观众状态**：已经获得价值，愿意表达自己的具体情况。

**目标**：识别评论区主要人群和下一轮该讲的分支。

**有效内容**：互斥选项、真实问题、接住一条评论继续证明。

**避免**：连续问“是不是”“有没有”；让观众打字后完全不回应；只有点赞关注指令。

### 5. 痛点延伸

**观众状态**：问题已明确，开始判断产品是否真的适用。

**目标**：用产品、演示和证据承接刚才确认的痛点。

**有效内容**：现场操作、细节特写、前后对比、来源证明、流程演示、边界说明、异议处理。

**避免**：突然朗读功能列表；用“高级、智能、专业”替代证据；回避限制条件。

### 6. 行动指令

**观众状态**：理解价值，但需要一个低摩擦且可信的下一步。

**目标**：明确现在做什么、会得到什么、条件是什么。

**常见动作**：点击商品、选择规格、领取真实权益、申请试用、提交资料、预约评估、私信关键词。

**避免**：所有品类都用“321 上链接”；软件和高客单服务使用实物库存话术；制造虚假倒计时。

## 阶段权重

六步都应出现，但篇幅由决策逻辑决定：

| 类型 | 应加重 | 应控制 |
| --- | --- | --- |
| 低客单、强视觉实物 | 展示、权益、行动 | 长篇方法和行业解释 |
| 美妆与效果型产品 | 适用人群、近景证据、边界 | 绝对功效和假对比 |
| 食品与来源型产品 | 场景、试吃、来源、信任 | 空泛营养承诺 |
| 3C 与参数型产品 | 测试、兼容、参数解释、售后 | 纯情绪催单 |
| 软件工具 | 工作流演示、能力边界、试用动作 | 只讲功能数量 |
| 课程与知识产品 | 方法交付、适用人群、交付内容 | 结果保证 |
| 高客单服务 | 诊断、案例证据、交付流程、预约 | 直接逼付和虚假稀缺 |

这张表只指导权重，不替代实时分析。

## 多轮循环

后续循环可以按以下维度换切口：

- 人群：新手、进阶用户、团队负责人。
- 痛点：不会选、不会用、效果不稳、流程太碎。
- 证据：演示、细节、来源、案例、参数。
- 异议：贵、不适合、不会用、已有替代品、售后担忧。
- 场景：日常、活动、送礼、团队协作、紧急任务。

每轮开头承接真实评论或上一轮问题，避免假装刚开播。

## 常见结构错误

1. 拉新阶段就完整介绍品牌和功能。
2. 痛点重复三分钟，却没有方法或证据。
3. 方法阶段只是在说产品很好。
4. 互动问题没有分支意义。
5. 演示结束后重新朗读一遍所有卖点。
6. 行动指令与交付方式不匹配。
7. 每一轮只替换同义词，没有新的信息或证据。
