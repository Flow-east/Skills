# 图片与视频

先确定是从零生成、使用参考、局部编辑、图生视频还是视频延展。这些操作影响 Prompt 所需信息，比“营销/教育/娱乐”的行业分类更直接。

## 图片

**从零生成**：把用途转成画面要求。主体及其关系、构图、媒介或风格、需要的文字及留白、光线与材质，按任务需要选择。没有必要每次写镜头焦距、8K、获奖作品等修饰。

**参考生成**：实际查看参考图，并说明每张图负责什么：主体身份、构图、色彩、材质还是风格。引用多张参考时处理彼此冲突，不能暗示目标工具必然支持多图。

**局部编辑**：明确改动、位置、参考用途和需要保持的特征。例如调整衣服颜色时，保留姿态、面部、背景与构图。只写与本次修改有关的保持项，避免加入多余禁令。若目标工具支持遮罩，把遮罩操作放在使用说明中。

**图中文字**：给准确文案、相对位置、层级与可读性要求；精确排字不稳定时，建议将背景生成与排版分开。参数、负向提示词与参考权重仅在确认目标工具支持时提供。

## 视频

**文生视频**：关注主体做什么、镜头怎样变化、动作的先后与持续时间，以及需要的声音。短片承载不了的多场景剧情，应建议拆成镜头或先生成分镜；用户明确要求单镜头时保留该约束。

**图生视频**：先看输入图，并说明哪些元素动、怎样动、镜头是否移动、哪些内容需稳定。Veo 官方指南对这种输入建议聚焦运动，避免重复描述图中已有外观；这是带工具范围的建议，不能写成所有视频模型的永久规则。[S4](sources.md)

**首尾帧、参考角色、视频编辑**：先核实目标工具支持的输入方式。图像角色描述、参考素材与生成参数各有作用，不把一种机制当成另一种。

把“有电影感”翻译为与目标有关的选择，例如固定近景、缓慢推进、光线反差或环境声音。用户不懂术语时提供直观解释，不必要求他先知道镜头名称。

## 工具适配

内置资料不锁定模型版本、参数旗标或语言偏好。用户指定工具时先参考可用的已核验资料；涉及会变化的能力、参数、时长、画幅时查官方文档，并记录核验日期。无法确认就输出通用描述，把不确定配置留在说明里，不杜撰旗标。

同一 Prompt 在不同版本和设置下结果可能不同。案例需要关联工具、参数和参考素材；跨工具复用时重新核对，不宣称直接迁移就能复现。
