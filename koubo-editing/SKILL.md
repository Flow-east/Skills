# 口播剪辑

先决定保留什么、如何组织和强调，再用模板实现视觉与声音。根据素材和用户目标决定是否使用贴纸、音效、转场或生图；不要把模板可用元素当成必须出现的元素。用户只要求分析时交付分析，不自动渲染或生成素材。快速预览入口见 [快速使用](references/quickstart.md)，精细计划与运行依赖见 [计划规范](references/plan-format.md) 和 [运行说明](references/runtime.md)。

## 工作流程

1. **核对素材与转写。**用 `ffprobe` 核对画幅、旋转、时长和音轨。复用可信逐词转写；否则按 [运行说明](references/runtime.md) 选择本地转写后端。保留原 ASR 及待听校项，专名、数字和听不清处对照原声确认，不凭猜测改词。
2. **做内容精剪。**按源时间标出论点、步骤、重复、口误、现场沟通与可删内容；逐处说明保留或删除的理由。删掉的语音不能在相邻片段合并时带回；前置结论不能脱离限定条件，结尾保留完整词句和尾音。需要编译决定时使用 `scripts/make_cut_plan.py`，不要把自动候选当成语义审核。
3. **先写创作方案。**按 [通用创作决策](references/creative-direction.md) 比较原开头、问题/结论前置等真实源句候选，明确正文如何兑现开场。逐段决定镜头景别、字幕层级、是否使用音效、转场和隐私遮挡，写入 `creative-brief.md`；允许明确选择“不使用”。用户已确认的结构在局部改稿时不要擅自重排。
4. **选择整套模板。**从 [模板目录与状态](references/template-library.md) 查适用画幅、字幕结构、字体、词标、动效和镜头约束；选择模板不等于仅换颜色。参考模板的专属规则按需读取相关批次文档。若所需能力未实现，调整方案或说明限制，不通过未知字段假装已执行。未获明确验收的模板按目录规则使用 `template_delivery: preview`。
5. **编排视觉与声音。**用 [镜头运动](references/camera-motion.md) 的语义节点安排缩放与构图；少量重点词可按 [关键词贴纸](references/keyword-stickers.md) 单独标注。音效先从 [音效索引](references/sfx-catalog.md) 按语义筛选，再按 [声音设计](references/sound-design.md) 试听 A/B 并写入显式 `sound_events`；不要逐句、随机或无条件加声。转场只用于明确的镜头边界，不能截断话音。
6. **编译并渲染。**按 [计划规范](references/plan-format.md) 保存 `plan.json`，区分源时间与输出时间。默认保持源画幅；比例不符时显式决定裁切或补边并写理由，不能默默加黑边或裁掉主体。执行 `scripts/render_template.py plan.json --out-dir 输出目录`；编码前通过实际字体字形覆盖和布局检查。
7. **验收与交付。**检查成片完整解码、音视频时长和结尾、字幕原文与 SRT、首中尾原尺寸画面、切点声音及贴纸/隐私覆盖。必要时回转写成片。未解决的听校或审美问题标为预览待确认，不把机器测试当成人工验收。交付有声 MP4、`creative-brief.md`、计划、字幕和 QA 结果；不自动发布。

## 条件性规则

- **贴纸与生图：**优先复用合适素材或用文字、箭头、形状表达抽象概念。只有内容确实需要具体插图且缺素材时，才调用当前环境中可用的图像生成工具或技能；按其自身说明及用户授权处理外发、费用和失败重试。没有可用能力时跳过生图或说明缺口。透明素材须检查真实 alpha，不把黑底或棋盘格当透明。
- **人像与画幅：**`protected_regions` 需根据当前画面和镜头变化编写，不能把旧视频坐标照搬；检查脸、嘴、手势和字幕安全区。画幅适配与打码是两项独立决定，不为省去遮挡而擅自缩窗或裁掉必要信息。
- **隐私遮挡：**先识别确需保护的画面、声音和文字；用户指定的样式优先，必要时读 [柔边遮挡](references/privacy-soft-mask.md)。遮挡须贯穿冻结帧、尾帧延长和实际编码结束时间，并检查字幕、缩略图与附带文件；未核验不能宣称已脱敏。
- **内容与授权：**字幕排版不能更改原话含义；内置音效和字体的来源、许可见各自目录。素材外发和付费生成需本次任务明确授权，不因工具可用就默认执行。

验证：`python3 -m unittest discover -s <SKILL_DIR>/tests -v`，以及 `python3 <SKILL_DIR>/tests/smoke_test.py`。测试通过不能替代当前视频的内容和视觉验收。
