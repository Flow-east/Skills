# 第三批前三套：双语分层校准模板

先完成 `creative-direction.md` 中的创作方案，再用本规则实现。三套是可运行校准版，非开拍原工程，未获逐套审美验收；显式使用 `template_delivery: preview`。数量以台账为准，不能把第三批10套称为已经全部完成。名称相同的旧配置仍保留兼容，下面的明确variant ID才指向新分层实现。

| 目标 / variant | 独立设计 |
|---|---|
| kp-01 / `ref_bired_v1` 高级红·双语 | 白色斜衬线标题+红字白边副标题；白正文/更大红衬线重点词；最多两组错位中英短语；可独立右侧红字词标 |
| kp-02 / `ref_biluxe_v1` 轻奢白·双语 | 银白毛笔标题+黄副标题；手写感中文、衬线英文；最多两组错位短语；可有独立上方毛笔重点字与原创闪点 |
| kp-03 / `ref_biblue_v1` 经典蓝·双语 | 半透明左对齐标题条；青绿粗重点词/细灰白连接词混排；单组居中中文与独立英文；不另堆任意词标 |

共同遵守 `sample-led-scenes.md` 的输出时钟、词流一致性和保护区。3:4、9:16为当前声明比例；每条视频仍需检查人物/手势和字幕。不得只按名称把经典蓝做成纯蓝色。

## 中文与英文分轨

每个 `scene_captions[].phrases[]` 必须有唯一 `id`；主字幕仍与 `clips.words` 的中文词流一致。`runs` 只能用body/keyword角色，不任意覆盖模板颜色。独立顶层 `scene_translations`：

```json
{
  "phrase_id": "p1",
  "source_text": "先检查流程",
  "text": "Check the workflow first.",
  "language": "en",
  "start": 1.1,
  "end": 2.6,
  "review_status": "reviewed",
  "reviewer": "实际进行语义复核者及范围"
}
```

此示例时钟为输出时间，须落在p1中文短语的起止范围内，不是源时间。每个中文短语对应一条英文，不漏译、不重复锚定；英文可晚入或早退，不强制跟随中文重入。`source_text` 必须与对应中文完全一致，中文修改后旧译文阻断，需重新复核。若中文被切成孤立语气尾字或极短意群，先合并成可读短语再翻译，不能逐token机械翻译。

允许 `draft`，但必须显式preview；reviewed必须写真实审查来源，不能冒称用户已确认。渲染器不翻译、不理解译文是否准确，Codex须核对否定、数字、条件、专名与上下文。英文自动按词换成最多两行，允许有限缩小，不截断、加省略号或无限缩小；超长需重新分句/忠实精炼。语义和阅读时长仍须人工式复核。

渲染输出保留 `captions.srt`（仅中文）、`captions.en.srt`（仅英文）、`translations.json`（独立译文与复核元数据）。不要将英文写入中文ASR或使用旧 `english_map`/phrase.english 混层。

## 重点字与动效

高级红可使用既有 `scene_tags`，必须有语义理由；其它两套不接受该层。轻奢白支持 `scene_highlights`：`{start,end,text,phrase_id,reason}`；最多8字，必须摘自锚定中文并落在该短语时间内。位置绑定上方展示位，不能和标题同时间重叠，人物保护区碰撞仍阻断。它是强调层，不重复写入中文SRT。

模板允许的动作不是必须动作。是否缩放、是否加音效或镜头转场由创作方案决定；不因双色字幕出现就自动加音效。三套有独立有界camera_recipe。

## 差距与禁止冒充

- 全部字体为已有获授权替代字体，不是已确认开拍原字库；高级红倾斜标题是几何近似。
- 尚未复刻参考中逐词插入/显字的完整机制。
- 轻奢白有毛笔大字和随其入场的原创星芒点缀，但没有原样飞白银色纹理或真实动态粒子场。
- 经典蓝允许既有swipe空间效果，但它不是两段镜头重影交叠转场；本批对照不强行使用。
- 翻译、字幕排版和字形检查通过不等于正常速度试听、观感或用户验收通过。
