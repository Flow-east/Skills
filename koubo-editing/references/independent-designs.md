## 内容与视觉的边界

- 内容分析编写原话、删剪决定、重点词及其输出时间，不为视觉设计改写已经确认的字幕。
- 模板绑定 `caption` / `title` / `sticker` 的结构、字形、颜色、尺寸、布局、动画，以及 `camera_recipe`。
- 事件默认继承模板；手工 `position` / `caption_position` 是明确的作者覆盖，不能把上一模板的坐标批量复制进新模板。换模板做对照时先清除旧的位置/宽度/标题时长覆盖，只保留有理由的覆盖项。
- `caption_chars` 未指定时继承模板；作者 `caption_break_after` 仍保留。SRT 与渲染使用同一分组上限。
- 已明确编排的 `camera_motion` 不随换模板被覆盖。新视频仍需用所选模板的镜头规则编排语义节点，不把转写分段当镜头指令。专门做字幕包装对照时可固定镜头，明确告知。
- 每套只能在有限的预设区域内避让，不能每句随机改变位置；长句保持关键词完整，最多两行，无法安全排下应重新做语义断句。

## 安全区与人脸

`protected_regions` 是**作者根据实际画面检查后写入的输出时间区域**，不是自动人脸检测：

```json
{"protected_regions":[{"start":0,"end":8.5,"box":[0.2,0.23,0.76,0.66],"reason":"人工检查本段人脸和近景余量"}]}
```

坐标归一化，box 为 `[left,top,right,bottom]`。必须复核缩放高峰与手势，不能把上述示例照搬到另一人像。

- `caption.anchor` / `fallback_anchors` 与 `sticker.anchors` 是模板定义的候选区域。
- 布局提前计算整个事件的动画最大包围框，避让整个事件期间的人脸区域、标题和字幕；一个贴纸出现期间不因相邻字幕长度改变而跳来跳去。
- 没有安全位置时阻断渲染，不能悄悄遮脸或把字缩成不可读。
- `layout_qa.json` 记录模板与输出时间、包围框以及是否提供人脸区域。通过它不等于视觉验收。
- v2 四套目前不支持双语伴随字幕、旧通用 card 和 eyebrow，遇到这些字段明确报错，不静默丢字或混入旧版式；应选择现有双语/卡片模板，或补齐相应专属设计。

## 如何验证“不是换皮”

用同一段真实口播做动态短样，包含标题、普通句、强调句和独立贴纸。先做短样，不直接生成四条完整版。

1. 检查实际编码后的整段帧序列，标题/贴纸出入场额外检查密集帧；静态对照只作辅助。
2. 核对正文、关键词、字牌是否完整可读，字体预检和布局预检均通过。
3. 比较结构、对齐、层级、位置规则和动画轨迹，不能只证明像素哈希不同或字体路径不同。
4. 区分“实现和技术检查通过”“本次素材目视检查”“用户审美认可”；不要把测试数当成达到开拍水平的证据。
5. 保留旧成片，新的输出目录与计划明确标记短样/完整版和改动范围。


## 实样优先与模板参考库（2026-09-17）

- 原校准工作使用过54条用户提供的预览与封面；这些实样不随公开技能分发。新任务应使用用户本次提供的参考，或仅根据随附契约说明进行原创实现。
- 该库只代表用户HTML列表，不代表当前官网的全部模板；不能称为54套可执行模板。不要把预览视频打包进对外交付的技能。
- 后续设计从这些实样的全片结构与密集动画帧出发，不再凭“文艺/编辑感”等自行联想。记录实样名称、用到的可见设计证据、未复原的内容。
- 后两套去掉手写下划线、细线黑板和信息条；不要在新模板中悄悄退回这些被否定的设计。
- `caption_line_breaks` 可按完整字幕文本指定换行字符位置（不改原文/时间），例如 `{"先不要急着去批评":5}` 输出“先不要急着 / 去批评”。不能断成“先不要急 / 着去批评”，也不能拆开完整重点词。`caption_tones` 可以为作者确认的反转/警示句指定 `warning`，在轻透雅粉样式中采用黄色强调；没有语义判断不要随机轮换颜色。
- 双行候选可依据词边界生成，但ASR单字不等于语义边界；必须目视复核。短句不硬凑双行。
- `keyword_stickers[].symbol="warning"` 仅用于作者判断的提醒/警示词；不对全部贴纸附加符号，不用否定叉号误表达“效率问题”。
- 对照样片保持前两套不动，后两套固定相同原话、音频、镜头轨道做动态短样，清楚标为“参考重制，待用户审美验收”。
