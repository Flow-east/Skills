# 语义音效：创作层与模板声音边界

音效库与视觉模板独立保存，**事件是否发生**由口播内容与同期声决定；模板只限制音色/强度。同一重点词的字幕、词贴和镜头动效算一个语义事件，原则上最多一个音效。新计划需显式启用；旧计划无 `sound_events` 时输出行为不变。`audio.cues` 是旧卡片提示音，不得与显式事件共存。

## 决策顺序

1. 剪后重新审视黄金约5秒：列出独立的句子/问题/结果；检查每句结束处有没有值得做声音标点的**完整语义**和人声空间。连续论述不按标点自动响。之后评估反差、清单切换、操作反馈、关键词，最后评估留白。
2. 检查原声是否已有提示音、环境/情绪声；检查尾字/尾气和下句进入时间。视觉落点可配轻点，结论句末可在尾音完成后轻落；声音有前导时按可听主击点对齐，不按 WAV 起点。没有足够空间则改用更短素材或不加，不能截掉人声。
3. 对每个候选写清作用、对应片段实例、时钟/词索引、对应视觉事件、选择的音色、为何未在其他句加声。先听 A/B；有盖话、串音、抢拍时调低或撤回。不能靠解码/峰值代替主观听审。
4. 来源有疑问（软件内素材、剪辑缓存或教学样片）时只做参考，不加入可分发技能资产；禁止未经核验提取。此前 Kenney UI 音效虽有 CC0 来源但风格不符，用户已否决；清单中标为 `rejected_by_user`，渲染器会阻断这些素材。优先从有真实声音的开拍成片/模板参考中分析音效角色、时间点、音色与花字/镜头的联动，再找**近似且允许技能使用的现成素材**。参考音轨只用于分析，不直接抽取进技能。74 种不同用途的现成音效已由用户决定全部保留，见 [可选音效索引](sfx-catalog.md) 和 `assets/sfx/catalog.json`；保留是准许按场景选用，**不等于自动逐句插入或无条件用完**。视频中每个具体声音仍要过时点、原声、语气与响度试听。

## 候选卡与 A/B 决策入口

先按内容结构列出开头问题、反差、章节、词标、转场及明确留白，不把“有素材”当使用理由。剪辑计划有逐词时间码后运行 `python3 scripts/sound_candidates.py /absolute/plan.json --out /absolute/sound-candidates.json`，得到同名 Markdown 决策卡。`auto_plan.py` 也会写 `_sound_candidates.json/.md`。候选卡只用词尾与下一句的成片间隙初筛，并受模板 `sound_style` 约束；可能漏掉无标点的重点词，也不能判断原声已有声音或画面是否适合，**不自动写 `sound_events`**。标注“leave_silent”是审查线索而不是必须无声。编辑者核对原声、语义、画面和素材后，按唯一语义事件选不超过一个候选，并解释其他边界为何不用。做同一画面、同一音轨的无声/有声短样，试听尾音、人声空间、击点、响度，再把满意的显式事件用于全片；未实际试听时保留 `original_sound_review:pending`，只称技术预览，不能伪称听审通过。无合适空隙应宁可不加。

## 可执行 JSON 契约（plan v2）

```json
{
  "audio": {"bed":"none", "cues":false, "sound_style":"premium", "original_sound_review":"pending"},
  "sound_events": [
    {"id":"opening-point", "clip_id":"hook", "word_index":16, "edge":"end",
     "asset_id":"common-005", "role":"keyword", "reason":"马上：结果提前给出", "gain":0.12},
    {"id":"opening-answer", "clip_id":"hook", "word_index":20,
     "asset_id":"common-064", "role":"sentence_end", "reason":"纠正：完整结果落点", "gain":0.10}
  ]
}
```

`clip_id` 必须对应唯一片段实例。锚点二选一：`word_index`（该片段 words 从 0 起，默认取词尾，`edge:start` 可改词头）或 `source_time`（原视频秒数，限该片段源区间）。编译后按帧映射到**成片时间**，`offset` 可在 ±0.20 秒微调；声音主击点落在锚点加偏移，前导会提前。`gain` 为 0–0.20 的线性幅度（默认 0.12）；素材自动做短边缘淡入/出，不压低人声。声音如溢出成片、同类叠加距离过近、样式不兼容、素材缺失或哈希变化，**报错而非静默跳过**。事件日志 `sound_events.json` 记录锚点、素材 SHA-256、样本起点、增益与原声审查状态；`qa.json` 声音项记录峰值和裁剪样本数。`original_sound_review:pending` 不阻止技术预览，但交付前必须真实试听并人工核对原声。

仅作为视觉模板的一阶声音约束：`premium`（克制，金色/深棕等代表样式）、`bright`（强调，荧光/亮粉等）、`minimal`（干净，黑白/白底等）；未配置的模板默认 `neutral`。这是候选约束，不表示 54 套均完成音效校准。Kenney 的六项仍在 `assets/sfx/catalog.json` 作为被否决记录，**不可用于新渲染**；包内许可原文在 `assets/sfx/Kenney-License.txt`，不是风格适配证明。新增74项来自多个原作者作品页的 CC0 HQ MP3 预览，技能保留原始预览文件和转换后的渲染 WAV、哈希、作者、许可与语义/分类元数据；`selection_status:approved` 表示用户同意全保留，可在**具体视频**中选择，不表示每条都适合模板，也不代表每个声音通过了单独的高分听审。`sound_events` 的 `role` 可取素材 `roles` 列表之一；生活拟音和长环境声只能在画面/内容真有对应动作或氛围时使用，不可把它们当成普通句末标点。第一次用在视频里还须对照 [开拍参考音轨核查](kaipai-sound-reference.md)，在短样中检查人声清晰度、冲击时点和风格。
