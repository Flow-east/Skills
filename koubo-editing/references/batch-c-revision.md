# C 批模板执行规则（tpl-neon-green～tpl-classic-deep-brown）

C 批是九套独立模板的可运行校准版，仍标记为预览，不把机器 QA 当用户审美通过。历史校准使用本地批处理脚本；公开包应按 `plan-format.md` 编写计划，随后由 `render_template.py` 编译；字体、状态、词标与 output-clock 镜头都必须来自契约。

| ID | 名称 | renderer kind | 关键结构 | 语义标注规则 |
|---|---|---|---|---|
| tpl-neon-green | 荧光绿 | neon | 轻白正文、荧光绿粗重点词、稀疏扫描线 | 只在原话有明确重复/动作概念时用荧光字面词标；圆窗不是默认效果 |
| tpl-ultra-purple | Ultra·紫 | purple | 横排双语或独立直立竖列，译文独立时钟 | 竖词标必须引用当前短语，不能补造身份；直立短语需要 x/y/原因 |
| tpl-vivid-blue | 靓眼蓝 | vividblue | 前段棕色紧贴标签态，后段青白错位大字 | 标签引用原话重点，不复制新闻蓝的纸片结构 |
| tpl-colorful-pop | 明快彩彩 | colorful | 白小句、黄展示句、红强调句 | 紫色细边标签仅保留口播已经说出的特征，不增加产品卖点 |
| tpl-oriental-ink | 淡雅新中式 | ink | 细白手写正文、窄纸条黑字、留白 | 克制使用纸条，不自动生成侧词标或大卡片 |
| tpl-antique-mint | 古雅水绿 | mint | 透明绿字、薄荷圆底黑字、按实际字宽计算下划线 | 下划线必须引用原句；薄荷侧词标独立且带原话锚点 |
| tpl-red-torn-paper | 撕纸红 | tornred | 红色警示态与逐字不规则纸片 | 纸片是文字状态；说明图卡需要真实已审素材、版权和隐私核验，缺少时不生成 |
| tpl-warm-orange | 暖系橙黄 | warm | 每句独立橙底、暖黄重点词、最多三层错位 | 短词强调与本句同步，不添加通用大卡片 |
| tpl-classic-deep-brown | 古典深棕 | deepbrown | 深棕粗正文、米色关键词、金砂书法标题 | 参考仅约4秒时不补造更多状态；仅保留短词标和短开场暗角 |

## 通用约束

- 模板差异必须同时体现在字体、字幕结构、位置、重点词、词标、动效和镜头，不能只换颜色。
- 词标只能引用当前可见短语，带 `phrase_id`、起止时钟和语义理由；没有语义依据不触发。
- 双语模板 `scene_translations` 独立于中文 ASR，译文有独立 SRT，不参与主字幕词流一致性。
- 圆窗、暗角和其他 `scene_canvas` 只在契约允许且有构图理由时使用，不能作为隐私或排版捷径。
- 所有模板保留“技术/视觉初审”和“用户审美验收”分离状态；没有逐套确认不能写 `accepted`。
- 音效专项仍与模板相对独立，C 批不宣称完成音效库或自动配音效。
