# 独立关键词贴纸与字体

## 语义选择
主字幕负责完整原话，独立贴纸负责少量重点的视觉标注。优先否定/提醒、步骤中的具体工作、关键判断、结论。每条可以只选少量节点，不按重点词数量铺满；避免同时多贴纸，也不重复写整句字幕。抽象概念用原创建模的字牌、符号与便签；真正需要具体物体插图且缺素材时使用当前环境可用、且获授权的生图工具，不把程序字牌冒充AI生图。

## 输出计划
顶层 `keyword_stickers`：
```json
[{"start":10.95,"end":13.5,"text":"先别急","reason":"强调别急着批评，不把执行力差当成结论","position":[0.73,0.095],"max_width":0.44,"time_space":"output"}]
```
时间为最终成片秒；改变剪辑须重新映射。文字1–10字符，不要无依据添加承诺或事实。重叠事件直接报错。选择人脸与字幕以外的空区；本片顶侧留白不是所有素材的固定规则，画面没有空间时少加或不用，不遮脸。检查动画入场、完全出现和退场的实际画面；字号/描边/阴影都计入安全区。

贴纸在镜头缩放之后绘制，独立于主字幕；不随人像缩放。模板 `sticker_style` 决定 cutout（轮廓字牌）、bubble（圆角字牌）、paper（便签）、seal（双框字牌），禁止每句随机换造型。

## 字体整套绑定
- `font` / `body_font`：正文。
- `keyword_font`：关键词。
- `title_font`：标题。
- `sticker_font`：独立贴纸。
- `font_index` 或 `<role>_font_index`：TTC字体集合中的实际字形索引，预检和渲染相同。
- 相对字体路径以技能根目录解析，不能依赖开发目录的绝对路径；随技能保留新增字体的来源、SHA256和授权文件，不打包系统字体。

当前新增得意黑、霞鹜文楷、站酷快乐体；另启用本机宋体组合。一个模板可有分工明确的字体配对，例如正文黑体+得意黑重点字，不意味着一条视频逐句随机换字族。

当前四套：orange_hook（冲击大字/斜切字牌）、rounded_pop（气泡对话/圆角字牌）、ink_note（参考轻透雅粉的粗宋体错落双行/无底重点词）、cream_serif（参考基础白金的厚黑体标题与轮廓字幕/重点词符号）。后两套旧文楷便签、宋体双框与黑色信息板已被用户否定，不再使用。它们不是开拍官方工程，字体为本地可用近似。具体规则见 [独立模板设计](independent-designs.md)，预览使用同一句原话和相同镜头。
