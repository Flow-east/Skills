# 关键词贴纸与插图

主字幕完整表达原话；独立贴纸只在少量关键判断、步骤或对比处提供视觉提示。抽象概念优先用模板字牌、箭头和形状。具体物体插图确有必要、又没有可用且获授权的素材时，才查找生图能力；不为展示工具而生图，也不让贴纸遮挡脸、手势和字幕。

## 发现与授权

1. 根据当前环境列出的技能名称/描述寻找已安装生图候选，可用 `python3 <SKILL_DIR>/scripts/imagegen_bridge.py discover` 辅助。尊重用户指定的技能；调用前阅读所选技能的完整说明，核对输出、参考图、外发数据及费用。不静默安装，不以名称匹配冒充能力验证。
2. 在本次调用没有有效授权时，向用户简洁说明：用哪个技能/服务、生成什么、会外发什么（普通提示词、口播片段、截图、人物参考等）、预计费用及上限。**每次需要新授权时都提供“仅当前视频”或“永久授权（可撤销）”**；多次选前者不妨碍以后改选后者。用户拒绝则不调用。
3. 仅在用户明确选择后用 `imagegen_bridge.py grant` 记录范围；`video-id --file <原片>` 计算当前视频标识，`check --estimated-minor <已确认上界>` 在每次外发前核对技能、服务、数据类别、视频与费用；零费用显式填 `0`，付费调用另填 `--currency`（如 CNY），额度按货币最小单位记录；费用未知时不调用。调用后用 `record-cost --id <授权ID> --actual-minor <实际扣费>` 记账；即使实际扣费超出授权也要记录并停止后续生成、重新确认。永久授权范围内无需逐视频重问；换服务、增加截图/敏感素材或费用超额时重新提供两种选择。`list`、`revoke --id` 可查看或撤销。本地授权记录不含密钥和片源，也不能覆盖宿主环境的网络/工具审批。无法持久化时说明并退回当前视频授权。
4. 按所选生图技能的说明调用；不自行拼接未公开接口。用户仅允许普通提示词时不上传原片或人物截图，精确文字由渲染器叠加。生成失败不静默换服务或无限重试；可改用模板字牌，硬性插图要求无法满足时说明。

## 插图计划与检查

生成图需保存透明素材，记录工具/服务和授权 ID；在 [计划格式](plan-format.md) 的 `illustrations` 写入文件哈希、语义理由和成片时钟。渲染器检查透明通道、画幅、字幕及受保护人物区域；编辑者仍须观看成片入场、中段、退场。原片无可避让空间时减少插图，不把打码贴纸与装饰贴纸混为一谈。

模板的 `sticker_style` 决定普通字牌外观，不逐句随机换造型。完整字体/字形配置见 `assets/template_contracts/` 和 `assets/fonts/manifest.json`。
