# 模板建设与创作执行分层

以下是模板库的建设重点，不是单条视频的执行顺序。单条视频必须先按 [通用创作决策](creative-direction.md) 完成结构、表现形式、声音、转场与隐私设计，再映射到模板。

模板库的建设重点为：

1. 字幕样式/字体/版式模板选择；
2. 镜头语言与语义标注；
3. 内容取舍与废话删除。

不能只用视频长短衡量剪辑效果。

## 1. 模板系统不是一个配色 profile

将模板拆成可独立组合的五层：

- `typography`: 字体、字重、字号比例、行距、中文/英文关系；
- `stroke`: 描边层数、颜色、粗细、阴影、立体挤压；
- `layout`: 标题、主字幕、关键词、标签的锚点和换行规则；
- `motion`: 入场、退出、插入、弹跳、轻推近的时长与曲线；
- `decoration`: 底色条、颗粒、射线、闪点、语义贴纸槽位。

每个模板是一个完整的 `template_manifest`，而不是只改变 `style_profile.accent`。

模板选择应在内容分析后、渲染前完成，并记录：

- 选择了哪个模板及版本；
- 为什么适合该内容/人物景别；
- 哪些元素来自用户参考样本；
- 哪些特征是基于参考重新设计的。

## 2. 54 套模板的实现策略

不应凭空生成 54 个名字或色板。应建立模板目录：

- 第一阶段：把用户下载的样本逐套拆成可观察参数；
- 第二阶段：将参数归并为字体、描边、标题条、字幕锚点、动效和画布状态的组合；
- 第三阶段：用真实抽帧回归，淘汰“换色但实际一样”的伪模板；
- 第四阶段：对每个模板标注适用内容、人物景别、双语能力、是否需要素材。

只有完成实测和回归的模板才进入可选目录。数量不足时宁可显示“已验证模板数量”，不能虚称有 54 套。

## 3. 镜头语言必须成为一等公民

把镜头事件从“可选 zoom 参数”升级成语义节点：

- `hook`: 轻推近或短促入场；
- `warning/negative`: 轻暗角、关键词标注、短暂定格感；
- `number/step`: 节点切换、数字标签、轻微构图变化；
- `conclusion`: 回到稳定中景，关键词落点；
- `cta`: 轻推近或强调框。

镜头变化必须受人物保护约束：

- 人脸、嘴部、手势不能被裁掉；
- 纵向 3:4 不能机械套 9:16；
- 每个缩放事件要有 `focus`、最大倍率和持续时间；
- 没有画面证据时不声称做了人脸检测；
- 先做少量节奏变化，再考虑多镜头拼接。

## 4. 贴纸是语义标注，不是装饰填充

关键词贴纸应绑定到少量重点词，而不是每句话生成一张图。计划中应记录：

```json
{
  "anchor_text": "重复劳动",
  "semantic_type": "warning",
  "asset_kind": "sticker-or-label",
  "need_generated_asset": false,
  "position": "right_middle",
  "start": 22.2,
  "end": 25.0,
  "reason": "把抽象的重复劳动变成视觉标注"
}
```

只有具体物体、人物、品牌图形等确实无法用文字/形状表达时，才考虑调用当前环境可用且获授权的生图工具。抽象知识内容优先使用原创标签、箭头、圈选、流程符号，避免无关插画。

## 5. 内容与创作决策先行，不等于只追求精简

内容分析的目标不是最大限度缩短，而是先确定讲述结构与表现意图，再为模板和镜头提供可靠节点：

- 哪些句子是钩子；
- 哪些词值得放大/贴纸标注；
- 哪些地方是步骤切换；
- 哪些内容是现场沟通/重录；
- 哪些自然口语应保留以维持信任感；
- 哪些句尾不能掐断。

输出必须区分：

- `keep`: 有效信息或人物信任；
- `compress`: 可微剪但不应破坏自然语气；
- `remove`: 现场沟通、重复重录、确认语；
- `needs_review`: 专名、数字、句尾、歧义词。

## 6. 实战验收顺序

每条视频先做三版小样：

- 3 秒开头：比较标题、字体、钩子动效；
- 8–12 秒重点段：比较字幕、贴纸标注和缩放；
- 5 秒结尾：检查句尾完整、CTA 和收束。

通过小样后再渲染全片。全片只做技术 QA 不能证明接近开拍；必须做同时间点抽帧对照。


## 命名参考

用户提供的开拍模板列表包含 54 个名称。名称本身体现了用户对模板的选择方式：先按整体气质/色系/用途识别，再进入具体模板，而不是先选一个“字体 profile”。当前已用于第一版落地的显示名：

- 高级红·双语
- 轻奢白·双语
- 经典蓝·双语
- 明快黄
