# 开拍参考声音：先有声证据，再找近似音源

用户否决 Kenney UI 提示音。音效选择不得因为现成/CC0/有元数据就自称接近开拍模板。当前用户提供的12条下载模板和本地54条预览中，有大量无音轨或全零静音；需要**实际解码检查**，不能只看视频含 `audio` stream。原核查表属于未分发的本地研究资料。对于新提供的样片需重新实际解码与试听。

1. 优先使用已确认的、真正有声的开拍成片和有声模板预览作声音参照；其余模板只作视觉参照。截取本地可听参考时间段，逐事件描述：内容语义、画面动作、音效开始/主击点/余响、音色形容与密度。语音、BGM、环境声、压缩伪峰与音效分开，不凭波形断言某声音是什么。
2. 不从参考或他人教学视频中分离音效并打包。按具体声学角色检索现成音效，核验外部编辑、商业发布和随技能分发权限；对两三个备选做同画面同人声 A/B。声音近似、是否抢话须**实际试听**；无听审时仅标候选，不进入 `approved`。可不加声，也不要以游戏 UI 声充数。
3. 有明确许可且经听审认可的文件，登记来源/原文件哈希/转换哈希/主击点/时长/适用模板风格，并将其 `selection_status` 设置为 `approved` 后才能渲染。被否决音源保持 `rejected_by_user`，不能通过改增益绕过。旧 `audio.cues`/`original-pulse` 是兼容旧计划的程序声；新视频默认 `audio:{"bed":"none","cues":false}`，不把这些旧声音当作已通过审美的开拍式音效。

## 本轮来源纠正：剪映内置音效

“现成音效”在本项目中不是“开拍模板原音轨”，也不是泛用 UI 音效包，而是用户熟悉的**剪映音效库**：例如按键/点击、提示/叮、弹出、转场扫动、综艺/搞笑、卡通、冲击/强调等可在剪映音效面板中搜索和试听的声音角色。

- 先以剪映的分类、搜索词、预览听感建立候选，不按文件名臆测。
- 不能把 Kenney 等游戏/UI 音效包当作剪映音效替代；用户已明确否决此方向。
- 若技能要脱离剪映独立渲染，必须另外确认剪映素材是否允许导出后随技能复制/分发。剪映内能使用，不自动等于可以打包到 Codex 技能。权限未确认时，素材只能作为“剪映选型参考”，不能写入活动库。
- 目标是复刻剪映音效的**角色与编排逻辑**：短促、可听击点、和花字/贴纸/缩放同一事件、在句末或重点处落下，而不是复刻开拍模板的固定音轨。
