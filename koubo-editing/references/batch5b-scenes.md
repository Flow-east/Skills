# 第五批中四套：深棕、姜红、黑黄、绿意

入口：`ref_deepbrown_v1`（古典深棕）、`ref_ginger_v1`（素雅姜红）、`ref_blackyellow_v1`（黑黄框框）、`ref_verdant_v1`（绿意漾漾）。四套是校准预览，尚非用户逐套验收的官方1:1复刻。音效专项已恢复为显式事件原型，旧计划仍不自动加音效，保留原声不等于已设计音效。

## 创作与字幕时钟

先读creative-direction.md，确定结构、开场、表现和隐私再选模板。已确认中文原稿不因参考卖点、模板名或繁中演示而改写。所有事件使用输出时钟；短语必须有唯一非空`id`，并保留与确认词流一致的text/runs。仅`body/keyword`角色，不自填fill、color、pointer或underline。

| kind | mode | 设计与句数 |
|---|---|---|
| deepbrown | normal | 单句；毛笔金色标题＋棕米反色粗正文，不把它当成前批金白立体字 |
| ginger | normal/display/impact | 小白字幕细弧角线、白斜衬线展示句、粉色大词；最多两句中置独立留屏 |
| blackyellow | normal/display | 黑色紧底白小字、黄白柔光衬线展示字；最多两句 |
| verdant | normal/compact | 重衬线绿白大字、轻量小字幕；最多两句错位留屏；标题为粗绿奶油边而非水绿毛笔卡 |

每句独立start/end，后句出现不重播前句动画。大字长度不足以安全放下时语义分句，不无限缩字。局部柔光已计入字体图片包络；不允许无界发光盖脸。

## 独立词标与留屏功能签

四套均可用`scene_tags`，必须`phrase_id/text/start/end/reason`，文本是原句中的片段，整个时间落在原句可见期内；side为left/right，只支持水平文字样式，不接受任意icon。

仅blackyellow和verdant接受`scene_callouts`。字段为`phrase_id/text/start/end/slot/side/reason`，1–10字符的原句片段，在原句可见时入场，可以跨句保留；slot为0/1，同侧同槽不能时间重叠。默认侧边两槽，必要时同时给归一化`x/y`；仍必须通过字幕/保护区/画面边界检查，不把坐标字段当作任意遮脸授权。黑黄是白底深字签，绿意是细绿底奶油字签，不能沿用紫色产品标签样式。

## 可选画布效果

- deepbrown可显式设置既有`vignette`，只压暗边缘，不是暖色调色器，不强制每段添加。
- verdant可显式使用`circle`，保持既有center/radius/background/reason；还必须有`composition_review`，记录对实际素材必要构图的复核。
- verdant circle新增可选`feather`，值为画宽比例，范围`.002..04`，建议短样验证后决定。没有此字段沿用硬边；旧模板不接受此新增字段，避免悄悄改变旧效果。

```json
{
  "kind": "circle",
  "start": 0.5,
  "end": 2.0,
  "center": [0.5, 0.4],
  "radius": 0.25,
  "feather": 0.012,
  "background": "#000000",
  "reason": "实际内容/参考上的构图理由",
  "composition_review": "实际核验此区间的人脸、嘴、手势和必要信息均保留，记录依据"
}
```

这是固定位置画窗，不是自动人脸跟踪或主体抠像，也不是隐私遮挡。不得为少做打码或给字幕腾位而默认裁人/缩人。没有依据则不加；人物移动无法保持必要构图时不用固定圆窗，不能拿合成图表通过当作真人通过。隐私层仍须覆盖最终编码尾帧，模板不免除这条规则。

## 繁中口径与参考缺口

黑黄框框使用本地授权Noto Serif SC角色字体。本轮对“寶寶推薦耐高溫抗摔檢查複製資料”等及繁中合成片做了字形预检，不声称覆盖所有异体字。保留用户确认原文，不自动简繁转换；缺字必须停下并明确处置，不能静默换字。原参考顶部英文小行尚未实现，不能把任意译文藏进中文ASR；若用户需要则先补受审查的独立英文功能。

古典深棕本地参考仅约4秒，不能推断全片所有设计；毛笔字形、金粉动画目前是授权字与固定原创纹理替代。姜红逐字进场、黑黄扫光/歪框、绿意不规则字形/小英文等仍有差距，见每套契约limitations。技术测试、编码抽帧、实际常速视听、用户审美四者分开记录。
