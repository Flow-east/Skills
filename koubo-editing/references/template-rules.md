# 原创模板系统

配置文件为 `assets/themes.json`。动画和字号随输出宽度缩放，默认720×1280、30fps；不把720p插值成1080p称为画质提升。

## list-cards：连续清单 / 工具推荐

开头提问卡；随后每个完整观点一张编号卡，场景小字 + 答案大字。同一布局、0.2秒轻缩放/上滑入场、0.1秒退场；答词到达时轻提示音；底部字幕按词级时码变色。只有主词落点才使用相关贴纸。不要提前拼接多段碎片，先保留一遍最完整的回答。

## knowledge：知识 / 方法

青绿强调色，小量段落卡。关键词只突出一句的结论或动作。避免情绪特效覆盖复杂解释。不因某句有“对”就删掉；它可能是正式观点的一部分。

## service：课程 / 服务介绍

米金强调色、偏稳重色板，较低音效强度。卡片展示真实问题/交付；不自行添加收益数字、承诺或CTA。当前与知识模板共享卡片动画骨架，不宣称有独立完整动效库。

## 位置与密度

标题在上方安全区、推荐卡片约71%画面高度、字幕约88%。这是初始布局，不是通用自动人脸避让。根据原片人物移动调整，不做未经验证的人脸检测声明。缩放默认1，仅确实需要时设1.02–1.06并指定焦点。素材宽度、位置和出现时间必须在计划中明确。

字幕与卡片可重复核心词，但不要一屏同时重复三套长句。快列表视频每句话通常1.5–3秒；若观众看不清先减包装或保留合理停顿，而不是无限加速。
